# Задание 1. Проектирование технологической архитектуры

### Определите стратегию масштабирования и отказоустойчивости

Используется горизонтальное масштабирование, так как вертикальное не увеличит потенциальную доступность приложения при поломках.

### Несколько зон

1. В каждой зоне будет свой кластер, потому что это повышает безопасность и устойчивость системы. Сами сервисы должны быть stateless, чтобы в разных кластерах просто раскатывать анралогичные копии сервисов с одинаковой конфигурацией. 
2. Для балансировки используется глобальный балансировщик, так как ожидаются поьзователи из разных регионов - мы хотим их распределять на ближайшие к ним кластеры.
3. Используется active-active стратегия, она позволяет достигнуть наибольшей доступности.
4. Для организмации БД стоит использовать репликацию и Patroni для управления, нужно делать бэкап раз в 15 мин исходя из RPO

### Определите, будете ли вы применять шардирование БД

Шардирование не нужно, так как объем данных небольшой на данном этапе.
